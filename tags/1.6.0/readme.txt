== Description ==

[demo](https://fatpony.me/plugins/socicon/)

The easiest way to add the social icon font [Socicon](https://socicon.teddypayet.com/) to your WordPress site! Instant access to over 300 social icons, Socicon is a *lightweight* alternative to FontAwesome for displaying social icons.

Socicon's original maintainers are no longer active. This plugin now bundles the font from the actively-maintained community fork at [github.com/Ybbet/socicon](https://github.com/Ybbet/socicon).

### Usage

See the [Socicon Documentation](https://fatpony.me/plugins/socicon/) for instructions on using Socicon on your WordPress site.

== Installation ==

1. Install Socicon either through your WordPress Plugins screen or by uploading the files to the /wp-content/plugins/ directory on your server.
2. Activate Socicon.
3. Begin adding Socicon icons throughout your site!

== Screenshots ==

For a full list of current icons please see the [Socicon Documentation](https://fatpony.me/plugins/socicon/)

1. Socicon Icons 1-24
2. Socicon Icons 25-48
3. Socicon Icons 49-72
4. Socicon Icons 73-96
5. Socicon Icons 97-109
6. Socicon includes the WordPress logo
7. Socicon also includes useful icons such as Mail so you can use Socicon for sharing links.
8. Looking to display a PayPal payment link on your site? Use Socicon to display a PayPal icon for quick identification.
9. Even RSS feed links can use Socicon’s RSS icon!

== Changelog ==

= v1.6.0 =
* Version bump, tested up to WordPress 7.1.0
* Switched the bundled Socicon font to the actively-maintained community fork at github.com/Ybbet/socicon (v3.10.1), since the original socicon.com maintainers are no longer active (see GitHub issue #12)
* Icon count increased from 167 to 324; see the full list above
* Renamed icon classes: `socicon-beam` is now `socicon-mixer`, and `socicon-endomodo` (a typo in the old font) is now the correctly-spelled `socicon-endomondo` — update any custom CSS or templates that reference these two classes directly
* Added a `socicon-x` class for the X (formerly Twitter) rebrand; the existing `socicon-twitter` class is unchanged and still works
* Dropped the bundled .woff2 font file, which the new upstream font no longer ships; the plugin now serves .eot/.woff/.ttf/.svg, which covers all supported browsers
